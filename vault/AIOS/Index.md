# AIOS Index - AI Operating System Main Index

## Overview
This is the main index for the AI Operating System (AIOS) files stored in the vault. 
These files are designed to be tool-independent and future-proof, allowing you to 
use them with any AI assistant that has access to your vault.

## Core Files

### Personal Dossier
- [[me.md]] - Your personal dossier that helps the AI understand you and how you work

### Navigation Maps
- [[Vault Map.md]] - Guide for how the AI should navigate your knowledge base
- [[Skill Map.md]] - Reference for what AI skills exist and when to use them

### Directory Structure
- `AIOS/me.md` - Personal preferences and working style
- `AIOS/Vault Map.md` - Navigation guide for the knowledge base
- `AIOS/Skill Map.md` - Skills and systems reference
- `AIOS/Skills/` - Individual skill files (created)
- `AIOS/Templates/` - Note templates for consistent formatting
- `AIOS/Workflows/` - Pre-built workflows for common tasks
- `AIOS/Logs/` - AI interaction logs and histories

## How to Use This System

1. **Start with me.md**: Ensure your AI assistant has read your personal dossier
2. **Consult the Vault Map**: Understand where to find information in your knowledge base
3. **Check the Skill Map**: See what skills are available for specific tasks
4. **Invoke skills**: Use skill trigger phrases or reference skills directly
5. **Provide feedback**: Let the AI know what works and what doesn't to improve skills

## Adding New Components

### New Skills
Create files in `AIOS/Skills/` following the format in Skill Map.md

### New Templates
Create files in `AIOS/Templates/` for consistent note formatting

### New Workflows
Create files in `AIOS/Workflows/` for multi-step processes

## Philosophy
This system is designed to be:
- **Tool-independent**: Skills are stored as markdown, not locked into any specific AI
- **Future-proof**: Can be used with any AI assistant that can read files
- **Transparent**: You can see and modify exactly how the AI works
- **Extensible**: Easy to add new skills, templates, and workflows
- **Private**: Your knowledge and AI interactions remain in your control

## Getting Started
1. Read [[me.md]] to help the AI understand you
2. Review [[Vault Map.md]] to understand your knowledge base structure
3. Check [[Skill Map.md]] to see what capabilities are available
4. Begin by asking the AI to help you create your first skill or organize a section of your vault
