# Daily Routine Workflow

This workflow outlines the daily routine for managing knowledge and tasks using the AI Operating System.

## 🌅 Morning Brief (5-10 minutes)

1. **Check AIOS Daily Brief**
   - Review [[vault/AIOS/Skills/daily-brief.md]] for today's priorities
   - Note any scheduled meetings or deadlines

2. **Review Vault Map**
   - Check [[vault/AIOS/Vault Map.md]] for knowledge base structure
   - Identify areas that need attention today

3. **Set Intentions**
   - Open or create today's daily note
   - List 3 top priorities for the day
   - Review any carryover tasks from yesterday

## 📚 Work Session (Throughout the day)

1. **Capture Everything**
   - Use [[vault/AIOS/Skills/quick-append.md]] to add notes as you work
   - Use [[vault/AIOS/Skills/verbatim.md]] for important quotes or exact text
   - Create new atomic notes for significant ideas or decisions

2. **Organize Knowledge**
   - Periodically run [[vault/AIOS/Skills/knowledge-organizer.md]] to file new notes
   - Use [[vault/AIOS/Skills/link-weaver.md]] to connect related notes
   - Apply [[vault/AIOS/Skills/tag-gardener.md]] to maintain consistent tagging

3. **Maintain Focus**
   - When switching contexts, briefly note what you're leaving off
   - Use [[vault/AIOS/Skills/cascade.md]] to break down large tasks
   - Apply [[vault/AIOS/Skills/harmonize.md]] to resolve any conflicts in understanding

## 🔄 Evening Routine (10-15 minutes)

1. **Daily Log**
   - Run [[vault/AIOS/Skills/daily-log.md]] to reflect on the day
   - Capture accomplishments, challenges, and learnings
   - Note any unfinished tasks for tomorrow

2. **Knowledge Maintenance**
   - Run [[vault/AIOS/Skills/sanitize.md]] to clean up formatting
   - Use [[vault/AIOS/Skills/collator.md]] to gather related information
   - Run [[vault/AIOS/Skills/navigation-janitor.md]] to improve discoverability

3. **Prepare for Tomorrow**
   - Review and update tomorrow's daily brief
   - Set priorities for the next day
   - Ensure all notes from today are properly filed

## 🔄 Weekly Integration (End of week)

1. **Weekly Review**
   - Run [[vault/AIOS/Skills/weekly-review.md]] on Friday afternoon
   - Review accomplishments, patterns, and insights
   - Plan for the upcoming week

2. **Skill Maintenance**
   - Run [[vault/AIOS/Skills/skills-janitor.md]] to maintain and improve AI OS skills
   - Consider creating new skills for repetitive tasks
   - Update [[vault/AIOS/Skill Map.md]] with any new skills
