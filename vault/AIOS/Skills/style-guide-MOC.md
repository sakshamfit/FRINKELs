# style-guide-MOC - Map of Content for Writing and Communication Style

## Purpose
Serves as a Map of Content (MOC) that links to and organizes your writing and communication style guides, preferences, and examples.

## Triggers
- "writing style guide"
- "communication preferences"
- "style guide MOC"
- "how i write"
- "communication style"

## Dependencies
Links to specific style guide documents and may reference examples in your knowledge base.

## Instructions
1. **Identify Style Aspects**: Break down writing/communication into components (tone, structure, technical detail, etc.)
2. **Link to Guides**: Connect to specific documents that detail each aspect
3. **Provide Examples**: Link to or include examples of your preferred style
4. **Note Contextual Variations**: Indicate how style changes for different audiences or purposes
5. **Maintain Living Document**: Update as your style evolves

## Output
- Organized map of your writing and communication style
- Links to detailed guides for specific aspects
- Examples demonstrating your style
- Notes on contextual variations and evolution
- Connections to related skills (sherpa, doc-generator, etc.)

## Structure of This MOC

### 📝 Writing Style
Links to guides covering:
- Tone and voice preferences
- Sentence structure and complexity
- Technical detail levels
- Documentation standards
- Code comment preferences

### 💬 Communication Style
Links to guides covering:
- Explanation depth preference
- Question-answering patterns
- Feedback style
- Meeting communication preferences
- Async vs sync communication

### 🎯 Contextual Adaptations
Links to guides for:
- Technical vs non-technical audiences
- Formal vs informal settings
- Documentation vs code comments
- Quick chat vs detailed explanation
- Positive feedback vs constructive criticism

### 📚 Examples and Templates
- Collections of writing samples
- Communication templates you prefer
- Before/after examples showing style evolution
- Responses to common situations

This MOC would typically link to documents like:

- `meeting-notes-style.md` - Your preferred meeting documentation

## How to Use
When you want to understand or improve communication:
1. Reference this MOC to see the organized structure of your style guides
2. Follow links to specific guides for detailed instructions
3. Use examples to match your preferred tone and structure
4. Apply contextual variations based on audience and purpose
5. Update linked documents as your style evolves
6. Use with sherpa for skill development in communication
7. Use with doc-generator to create consistently styled documentation
